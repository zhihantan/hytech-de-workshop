# Hytech · Data Engineering with Databricks — MT5 Trade Lakehouse Workshop

Hands-on, 2 × half-day workshop (Mandarin) for Hytech's Shenzhen data-engineering team.
Participants build a production-style **trade lakehouse**: DMS-style MySQL CDC files → Lakeflow
Spark Declarative Pipelines (bronze → silver → gold) → a Lakeflow Job with a data-quality gate,
for-each reconciliation, Run-if alerting and repair runs, governed by Unity Catalog and observed
with system tables, plus Genie Code and AI Functions.
